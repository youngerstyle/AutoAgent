# TEAMHQ 工作空间 V2 实施计划

## 阶段一：拆除旧壳

- 移除顶部按钮导航和办公室旧三列布局。
- 删除可调宽任务栏、Canvas 高度等遗留状态。
- 保留 Agent Thread、Ticket Inspector、模型与档案编辑能力。

## 阶段二：建立空间框架

- 建立全局 Rail、项目 Context Bar 和页面 Stage。
- 使用统一状态色、尺寸与密度规范。
- 引入标准图标，不再用文字按钮代替熟悉操作。

## 阶段三：重建办公室

- 建立 Mission 指挥台。
- 使用完整办公室环境资产建立可感知的空间，不再用网格、区域框和流程图模拟办公室。
- 每个智能体以岗位人物、状态点和短气泡落在真实工位上；运行、需回复、失败和选中状态不改变工位尺寸。
- 建立紧凑的工作动态时间线与底部智能体对话抽屉。
- 保证 Human 消息和 Engine 状态仍走原有真实接口。

## 阶段四：重整管理页面

- 项目页改为项目目录与当前项目工作台。
- 人才页改为全局人员档案工作台。
- 模型页保持独立基础设施管理。
- 运营页只展示三大 Engine 的事实摘要。

## 阶段五：验收

- `1280×720`、`1600×900` 逐页浏览器检查。
- 验证导航、项目切换、Agent 选择、对话和表单可达。
- 检查无横向溢出、遮挡、控制台错误。
- 运行完整测试与生产构建，完成代码审查后提交。
