# TEAMHQ 工作空间实施计划

## 阶段一：页面骨架

- 将顶层导航调整为办公室、项目、人才中心、模型服务、系统运营。
- 管理页面脱离办公室项目侧栏，获得完整工作区宽度。
- 保留现有状态与 API，不修改 Engine 合约。

## 阶段二：办公室

- 把现有运行台整理为办公室导航、员工工位、Agent 对话和工作动态。
- 增加当前项目与团队摘要。
- 保留列宽、对话高度和自动滚动能力。

## 阶段三：项目与人才

- 新建项目中心，合并项目创建、列表、概览和团队实例配置。
- 将智能体档案库改造为人才中心。
- 明确 Profile 默认配置与项目实例覆盖关系。

## 阶段四：模型与运营

- 整理模型服务页的层级和文案。
- 新增系统运营页，展示真实 Workspace、Agent、Ticket、事件和待处理数据。

## 阶段五：验收

- 执行类型检查、前端构建和全量测试。
- 使用真实浏览器在桌面与窄屏视口逐页验收。
- 检查横向滚动、文本裁切、交互反馈和状态颜色。
- 完成代码审查后提交。
